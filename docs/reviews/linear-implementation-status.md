## Auth action inventory

The native-button review covers passkey/password signup and login; email collection, verification, new-code requests and resend; forgot/reset password; recovery request/verification/replacement enrollment; reauthentication; device request/approval/denial/cancellation; account email change/verification/resend; passkey add/rename/revoke; password save/remove; TOTP setup/confirm/remove and backup-code replacement/copy; session revocation and logout. Repeated rows use operation+row IDs to keep unrelated buttons from appearing busy. These identifiers remain local UI state and are not telemetry.

Google SDK loading and provider callbacks are distinct from native form submission. The owner selected supported GIS styling. Its provider-owned control is an explicit technical exception to a custom Visomi glyph inside each button; one status announces processing, while native retry actions use the shared in-button loader.
