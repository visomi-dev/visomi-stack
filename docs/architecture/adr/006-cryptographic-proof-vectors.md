# ADR 006: Cryptographic Proof Harness and Test Vectors

## Status

Proposed proof decision; production vault implementation remains out of scope.

## Decision

ZK-004 proves a provisional primitive set before vault work:

- AES-256-GCM with a 32-byte key and 12-byte nonce authenticates ciphertext and canonical associated-data bytes.
- HKDF-SHA-256 derives a 32-byte workspace key from a 32-byte VMK, a public salt input, and the domain-separated workspace identifier `themis/workspace-key/v1/<workspaceId>`.
- A workspace key is wrapped by AES-256-GCM under the VMK with the separate domain `themis/workspace-key-wrap/v1/<workspaceId>`.
- Nonce uniqueness is the encrypting caller's responsibility. The proof harness includes a reuse guard so future vault code can make that invariant testable.

The implementation is a deterministic Node.js proof harness, not a production vault or key store. Fixtures use synthetic bytes and fixed nonces; they do not contain live secrets. The exact password-to-VMK KDF, random nonce generation, hardware storage, rotation, recovery, and cloud protocol remain pending confirmation.

## Covered vectors and failures

`crypto-proof-harness.spec.ts` covers deterministic encryption/decryption, authenticated associated data, ciphertext tampering, wrong keys, HKDF workspace derivation, VMK wrapping/unwrapping, wrong workspace domain, invalid key/nonce lengths, corrupted ciphertext, version-domain mismatch, and nonce reuse.

The AES-GCM expected output is generated by Node's vetted `node:crypto` implementation and is suitable for comparison with Web Crypto or another runtime implementation. The harness intentionally exposes only encoded proof outputs, never plaintext key constants in a serialized envelope fixture.

## Compatibility boundary

The harness consumes the algorithm-neutral envelope contract from ADR 005 but does not alter envelope serialization or add production callers. Future implementations must reproduce these vectors, then obtain an independent security review before the provisional choices become a production commitment.
