# Open Design Agent Rules

- Import components directly from their source file; do not add barrels.
- Do not import `primeng/*` inside `shared/ui`.
- Do not import route or domain services inside `shared/ui`.
- Keep Tailwind classes literal in templates or static class maps.
- Prefer native HTML semantics before adding custom behavior.
- Use Angular CDK for overlay, focus, and accessibility behavior.
- Keep copy and examples in English.
- Use `data-slot` for projected content that receives special styling.
